# 🔐 Face Lock — قفل تشخیص چهره با وب‌کم

یک پروژهٔ آموزشی برای ویندوز که پس از ورود به حساب کاربری یا بازکردن قفل ویندوز، یک پنجرهٔ تمام‌صفحه باز می‌کند و با وب‌کم چهره را بررسی می‌کند.

> **توجه امنیتی:** این برنامه جایگزین Windows Hello یا قفل واقعی ویندوز نیست. تشخیص با OpenCV LBPH و وب‌کم معمولی انجام می‌شود و ممکن است با عکس یا شرایط نوری متفاوت فریب بخورد یا چهرهٔ صاحب برنامه را نشناسد. پروژه را برای یادگیری و آزمایش استفاده کنید.

## قابلیت‌ها

- بررسی چهره پس از ورود به ویندوز و پس از هر بار Unlock.
- قفل‌کردن ویندوز با `LockWorkStation` اگر چهره در ۵۰ ثانیه شناسایی نشود.
- بستن پنجره پس از شناسایی چهرهٔ ثبت‌شده.
- قفل‌کردن ویندوز با `Alt+F4` یا دکمهٔ بستن پنجره.
- بستن برنامه با میانبر `Ctrl+Shift+Q`؛ این میانبر ویندوز را قفل نمی‌کند.
- جلوگیری از بازشدن هم‌زمان چند نسخه از برنامه.
- ذخیرهٔ یک تصویر از اولین فریم هر اجرا در پوشهٔ `login_attempts/`.

برنامه پس از شناسایی چهره بسته می‌شود و تا ورود یا Unlock بعدی اجرا نمی‌ماند. اگر تشخیص ناموفق باشد و ویندوز قفل شود، بعد از واردکردن PIN وظیفهٔ زمان‌بندی‌شده برنامه را دوباره اجرا می‌کند.

## پیش‌نیازها

- Windows 10 یا Windows 11
- Python 3.12 یا جدیدتر
- وب‌کم قابل‌دسترسی

## نصب

پروژه را از GitHub دریافت و از حالت ZIP خارج کنید. سپس PowerShell را در پوشهٔ پروژه باز کنید.

### ۱. ساخت محیط مجازی و نصب وابستگی‌ها

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

نیازی به فعال‌کردن محیط مجازی یا تغییر دائمی Execution Policy نیست. وابستگی `opencv-contrib-python` لازم است؛ `LBPHFaceRecognizer` در بستهٔ معمولی `opencv-python` وجود ندارد. این دو بسته را هم‌زمان نصب نکنید.

### ۲. ثبت چهره

```powershell
.\venv\Scripts\python.exe face_lock.py register
```

در پنجرهٔ دوربین، برای هر یک از شش حالت نمایش‌داده‌شده Space را بزنید. با یک چهره در کادر و نور مناسب، برنامه تا ۷۵ نمونه در هر حالت می‌گیرد و سپس مدل را می‌سازد. با `Q` می‌توانید ثبت را متوقف کنید.

> اجرای دوبارهٔ ثبت چهره، نمونه‌ها و مدل قبلی داخل `face_data/` را پاک و جایگزین می‌کند. اگر می‌خواهید نسخهٔ قبلی را نگه دارید، پیش از ثبت دوباره از آن پوشه یک کپی خصوصی بگیرید.

### ۳. نصب اجرای خودکار

این دستور یک وظیفه برای حساب کاربری فعلی می‌سازد که هنگام ورود به ویندوز و هر بار بازشدن قفل اجرا می‌شود. PowerShell را در پوشهٔ پروژه باز کنید و بزنید:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_unlock_task.ps1
```

برای تأیید ثبت وظیفه:

```powershell
Get-ScheduledTask -TaskName FaceLockOnUnlock
```

### ۴. اجرای دستی و آزمایش

```powershell
.\venv\Scripts\python.exe face_lock.py
```

برای اجرای بدون پنجرهٔ کنسول، فایل `start_hidden.vbs` را اجرا کنید. پس از نصب وظیفه، اجرای خودکار نیازی به این فایل ندارد.

## کلیدها

| کلید | رفتار |
|---|---|
| `Ctrl+Shift+Q` | بستن برنامه؛ ویندوز باز می‌ماند |
| `Alt+F4` | قفل‌کردن ویندوز |
| دکمهٔ بستن پنجره | قفل‌کردن ویندوز |
| `Q` در حالت ثبت چهره | توقف ثبت نمونه‌ها |

اگر میانبر اضطراری عمل نکرد، می‌توانید در Task Manager پردازش `pythonw.exe` را ببندید. برای غیرفعال‌کردن اجرای خودکار:

```powershell
Unregister-ScheduledTask -TaskName FaceLockOnUnlock -Confirm:$false
```

## تنظیمات

مقادیر ابتدای `face_lock.py` را تغییر دهید:

```python
CONFIDENCE_THRESHOLD = 70  # کمتر = سخت‌گیری بیشتر در تطبیق
CAMERA_TIMEOUT = 50        # مدت بررسی دوربین، برحسب ثانیه
SAMPLES_PER_POSE = 75      # تعداد نمونه در هر حالت
TOTAL_POSES = 6            # تعداد حالت‌های ثبت چهره
HOTKEY_FORCE_QUIT = "ctrl+shift+q"
```

برای LBPH، مقدار confidence پایین‌تر تطبیق نزدیک‌تری است. بالا بردن `CONFIDENCE_THRESHOLD` شناسایی را آسان‌تر می‌کند، اما می‌تواند خطای پذیرش چهره‌های دیگر را بیشتر کند.

## داده‌های خصوصی

`face_data/` شامل عکس‌های ثبت چهره و مدل آموزش‌دیده است. `login_attempts/` تصاویر گرفته‌شده هنگام اجرای برنامه را نگه می‌دارد. این داده‌ها در `.gitignore` قرار دارند؛ پیش از انتشار مخزن، مطمئن شوید هیچ‌کدام به Git اضافه نشده باشند. فایل‌های `venv/` نیز وابسته به رایانهٔ شما هستند و نباید منتشر شوند.
